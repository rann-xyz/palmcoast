PALMCOAST is a sun-soaked, top-down open-world crime game about Rio Vega returning to a coastal city he never meant to love again. Steal cars, run twelve Caldera-crew missions, evade a five-star police response, collect hidden packages, and decide who owns the Golden Hour.

## Run it

```sh
npx tsx serve.ts
# then open localhost:8080
```
